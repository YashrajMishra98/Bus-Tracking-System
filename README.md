# Real-Time Bus Tracking System

A web-based bus tracking project built with React, Vite, Node.js, Express, and MongoDB. The app includes login and signup pages and provides the foundation for a real-time public transport tracking system.

## Features

- User login and signup interface
- Express backend server
- MongoDB connection setup
- React + Vite frontend
- ESLint configuration for development

## Tech Stack

- Frontend: React, Vite, CSS
- Backend: Node.js, Express
- Database: MongoDB
- Tooling: ESLint

## Getting Started

### Prerequisites

- Node.js
- npm
- MongoDB connection string

### Installation

```bash
npm install
```

### Environment Setup

Create a `.env` file in the project root and add your backend configuration.

```env
MONGO_URI=your_mongodb_connection_string
PORT=5000
```

### Run The App

Start the backend:

```bash
npm run server
```

Start the frontend:

```bash
npm run dev
```
